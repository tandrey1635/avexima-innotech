# Веб-сайт фармацевтической компании "Авексима Иннотех"
Адаптивный одностраничный сайт на чистом JavaScript и с использованием Яндекс.Карт API

## 🛠 Технологический стек

### Frontend
- **HTML5** - семантическая верстка, БЭМ-методология
- **SASS/SCSS** - вложенность, переменные, сброс стилей
- **JavaScript (Vanilla)** - нативный JS без зависимостей
- **Яндекс.Карты API** - интерактивная карта с кастомными стилями

## 🎯 Ключевые функции

### Пользовательский интерфейс
- **Эффекты стекла** - с использованием `backdrop-filter: blur(4px)`
- **Временная шкала научных этапов** - чистая CSS-реализация с визуализацией прогресса

### Интерактивные элементы
- Интерактивная карта с кастомными стилями

### UX/UI компоненты
- Липкая навигация для шапки при скролле
- Адаптивное бургер-меню для мобильных устройств
- Плавная навигация по странице

## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует современные подходы к веб-разработке и сочетает строгость фармацевтической отрасли с современными веб-технологиями для презентации научного потенциала.**
