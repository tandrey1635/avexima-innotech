# Сайт фармацевтической компании «Авексима Иннотех»
Коммерческий адаптивный веб-сайт фармацевтической компании на чистом HTML5/SASS и JavaScript с семантической версткой, с кастомной реализацией Яндекс.Карт, эффектами стекла и шкалой научных этапов.


## 🛠 Технологический стек

### Frontend
- **HTML5** — семантическая верстка, БЭМ-методология
- **SASS/SCSS** — модульная структура, сброс стилей, переменные, медиа-запросы
- **JavaScript** — работа с DOM, обработка событий
- **Яндекс.Карты API** — интерактивная карта с кастомными стилями


## 🎯 Ключевые функции

### UI/UX элементы
- Липкая навигация для шапки при скролле
- Плавная навигация по странице
- Адаптивное бургер-меню для мобильных устройств
- Интерактивная карта с кастомными стилями
- Эффекты стекла с использованием `backdrop-filter: blur(4px)`
- Временная шкала научных этапов - чистая CSS-реализация с визуализацией прогресса


## 🔧 Технические особенности

### Адаптивность
- Адаптивный дизайн
- Медиа-запросы
- Кросс-браузерная совместимость


**Проект демонстрирует навыки разработки коммерческих веб-сайтов для фармацевтической компании на чистом HTML5/SASS и JavaScript с адаптивным дизайном, интерактивными элементами и с кастомной интеграцией Яндекс.Карт.**
